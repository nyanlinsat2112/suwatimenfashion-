၃။ ထိန်းသိမ်းမှု နှင့် လုံခြုံရေး

အချက်အလက်များကို **Supabase** (Database Service) ပေါ်တွင် လုံခြုံစွာ သိမ်းဆည်းထားပါသည်။ Password များကို Encrypt လုပ်ပြီး သိမ်းဆည်းထားပြီး၊ ကျွန်ုပ်တို့ ကိုယ်တိုင်လည်း Password ကို တိုက်ရိုက် မြင်နိုင်ခြင်း မရှိပါ။ Admin Dashboard ကို Login/Password ဖြင့်သာ ဝင်ရောက်နိုင်ပါသည်။

၄။ Browser Storage (Cookies/localStorage)

Website ပေါ်ရှိ **ခြင်းထဲ ပစ္စည်း (Cart)** နှင့် **Wishlist** အချက်အလက်များကို သင့် Browser ၏ Local Storage ထဲတွင်သာ သိမ်းထားပါသည် — ကျွန်ုပ်တို့ ဆာဗာဆီ ပို့ခြင်း မရှိပါ။ Browser ပြောင်းလိုက်ပါက ဒီအချက်အလက်များ ပျောက်သွားနိုင်ပါသည်။
