စည်းမျဉ်းစည်းကမ်းများ

နောက်ဆုံးပြင်ဆင်သည့်ရက်: စက်တင်ဘာ ၂၀၂၆

SUWATI MEN FASHION ("ကျွန်ုပ်တို့") ၏ Website ကို အသုံးပြုခြင်း (ဝယ်ယူခြင်း၊ Account ဖွင့်ခြင်း၊ Order တင်ခြင်း အပါအဝင်) ဖြင့် အောက်ပါ စည်းမျဉ်းစည်းကမ်းများကို သဘောတူလက်ခံရန် သတ်မှတ်ပါသည်။

၁။ ဆိုင်အကြောင်း

SUWATI MEN FASHION သည် ကိုယ်တိုင် အင်္ကျီထုတ်လုပ်သည့် စက်ရုံမဟုတ်ဘဲ၊ အရည်အသွေးကောင်းသော အမျိုးသားဖက်ရှင် ပစ္စည်းများကို ရွေးချယ်ဝယ်ယူပြီး နေပြည်တော် ပုဗ္ဗသီရိမြို့မှ ပြန်လည်ဖြန့်ဖြူး ရောင်းချသည့် ဆိုင်တစ်ခု ဖြစ်ပါသည်။

၂။ ပစ္စည်း အချက်အလက်များ

ဈေးနှုန်း၊ Stock လက်ကျန်၊ ပစ္စည်း Description များကို တတ်နိုင်သမျှ တိကျစွာ ဖော်ပြထားသော်လည်း၊ လူကိုယ်တိုင် စစ်ဆေးမှု အမှားအယွင်းကြောင့် ကွာဟမှုရှိနိုင်ပါသည်။ ထိုသို့ ဖြစ်ပေါ်ပါက Admin မှ ဆက်သွယ် အသိပေးပါမည်။

၃။ Order နှင့် ငွေပေးချေမှု

  • Order တင်ခြင်းသည် ကမ်းလှမ်းချက်တစ်ခုသာ ဖြစ်ပြီး၊ Admin မှ ငွေပေးချေမှု အတည်ပြုမှသာ Order အတည်ဖြစ်ပါသည်။
  • ငွေပေးချေမှုကို **KBZPay** ဖြင့်သာ လက်ခံပါသည်။
  • Stock ကုန်သွားပါက Order ကို ငြင်းပယ်ခြင်း (သို့) ငွေပြန်အမ်းခြင်း ပြုလုပ်နိုင်ပါသည်။

၄။ ပို့ဆောင်ခြင်း

နေပြည်တော်အတွင်း ၁-၂ရက်၊ တခြားမြို့များ ၃-၅ရက်အတွင်း ပို့ဆောင်ပေးပါသည်။ ပို့ဆောင်ရေး ကုမ္ပဏီများ၏ လုပ်ငန်းလည်ပတ်မှုကြောင့် ကြန့်ကြာမှု ဖြစ်ပေါ်နိုင်ပါသည်။

၅။ ပြန်လည် လဲလှယ်ခြင်း / ပြန်ပေးခြင်း

ပစ္စည်း ချွတ်ယွင်းချက် (ပျက်စီးခြင်း၊ မှားယွင်းစွာ ပို့ဆောင်ခြင်း) ရှိမှသာ ပြန်လည် လဲလှယ်ပေးပါမည်။ Order လက်ခံရရှိပြီး **၂ရက်အတွင်း** Messenger/Viber ဖြင့် ဓာတ်ပုံနှင့်တကွ ဆက်သွယ်အကြောင်းကြားရပါမည်။ စိတ်ကြိုက်မဟုတ်၍ (Size မလိုက်ခြင်းမှလွဲ၍) ပြန်ပေးခြင်းကို လက်မခံပါ။

၆။ Account အသုံးပြုမှု

Account ဖန်တီးသူသည် မိမိ Password ကို လုံခြုံစွာ ထိန်းသိမ်းရန် တာဝန်ရှိပြီး၊ Account မှတစ်ဆင့် ဖြစ်ပေါ်လာသော လုပ်ဆောင်ချက်များအတွက် တာဝန်ခံရမည် ဖြစ်ပါသည်။

၇။ တားမြစ်ချက်များ

  • False Order များ တင်ခြင်း
  • Website ကို Hack/ထိခိုက်စေရန် ကြိုးပမ်းခြင်း
  • အခြားသူ၏ Account ကို ခွင့်ပြုချက်မရှိဘဲ အသုံးပြုခြင်း

အထက်ပါ လုပ်ရပ်များ တွေ့ရှိပါက Account ကို ရပ်ဆိုင်း/ပိတ်သိမ်းနိုင်ပါသည်။

၈။ တာဝန်ကန့်သတ်ချက်

Website အသုံးပြုမှုကြောင့် ဖြစ်ပေါ်လာနိုင်သည့် သွယ်ဝိုက်ပြီး ထိခိုက်မှုများအတွက် SUWATI MEN FASHION မှ တာဝန်မယူပါ။

၉။ စည်းမျဉ်းများ ပြောင်းလဲခြင်း

ဒီစည်းမျဉ်းများကို အချိန်မရွေး ပြင်ဆင်နိုင်ခွင့် ရှိပါသည်။ ပြင်ဆင်ပြီးနောက် Website ကို ဆက်လက်အသုံးပြုခြင်းသည် စည်းမျဉ်းအသစ်ကို သဘောတူကြောင်း သဘောထားပါသည်။
